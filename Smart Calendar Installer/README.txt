SMART CALENDAR - WINDOWS INSTALLER

1. Double-click SmartCalendar-Setup.exe.
2. This installer is currently unsigned. Windows Smart App Control may block it
   completely; this cannot be fixed by choosing "Run anyway".
3. Installers signed with a valid, trusted code-signing certificate are needed
   to avoid this Smart App Control block. Signing must happen before sharing.
4. Follow the setup prompts. You can keep the suggested settings.
5. Start Smart Calendar from the desktop shortcut or the Start menu.

This installer is for 64-bit Windows PCs. Internet, Java, and MySQL are not
required to use the installed app. Calendar data is stored on each device and
is not automatically shared with other people.
